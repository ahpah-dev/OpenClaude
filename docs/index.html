Specifications

Concrete architecture. Plain local files.

No opaque cloud database or proprietary wrapper. Conversations, projects, and settings stay in readable JSON on your disk.

Desktop Application Native compiled Windows executable (OpenClaude.exe) with custom desktop shortcut icon, warm-parchment startup splash, chromeless app window, and Windows System Tray controller.
Model Backends Local Ollama (127.0.0.1:11434, zero API keys) and 9Router (localhost:20128/v1, 96+ OpenAI-compatible cloud & subscription routes).
Vibe Coding Protocol Structured <ocAction> streaming tags for write_file, edit_file, read_file, delete_file, and real-time SSE PowerShell execution with process tree cleanup.
Personalization First-launch display name onboarding, time-of-day literary greetings, warm parchment (#FAF9F5) & obsidian (#21201E) themes, custom Writing Styles, and full System Prompt editor.

Quick Start

Up and running in under a minute.

Clone the repository and launch OpenClaude.exe on Windows—or run the Node server on macOS, Linux, or Windows. 9Router and Ollama are detected and started automatically.

Download ZIP (Includes OpenClaude.exe) Browse Repository
WINDOWS DESKTOP APP + DESKTOP ICON 
git clone https://github.com/ahpah-dev/OpenClaude.git
cd OpenClaude
powershell -ExecutionPolicy Bypass -File .\Create-Desktop-Shortcut.ps1
.\OpenClaude.exe
CROSS-PLATFORM CLI (WINDOWS / MACOS / LINUX) 
git clone https://github.com/ahpah-dev/OpenClaude.git
cd OpenClaude
npm install && npm run build && npm start
